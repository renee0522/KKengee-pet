# 啃叽多人电子宠物 v2

本版本按需求修改：

- 虚拟货币统一叫「啃叽币」
- 普通玩家没有充值入口；只有「提交订单截图审核」
- 玩家上传付款截图和实际金额
- 管理员后台查看订单截图
- 管理员可设置兑换比例（默认 1 元 = 10 啃叽币）
- 管理员审核通过后，服务器自动把啃叽币赠给玩家
- 好友系统
- 好友 PK：30 秒内点击「快速吃！」累计吃到的食物次数，次数更多者获胜
- WebSocket 用于实时同步 PK 分数和结束事件
- 数据保存到服务端 data.json；正式上线建议换 PostgreSQL/MySQL

运行：
1. Node.js 18+
2. npm install
3. 设置管理员密钥 ADMIN_KEY
4. npm start
5. 打开 http://localhost:3000

注意：这是可运行的开发版/MVP，不是生产环境支付系统。真实上线时应加入 HTTPS、真正数据库、密码哈希、限流、权限隔离、图片存储、订单防重复审核等。


## 本次新增：啃叽旅游与洗澡
- 啃叽的快乐值会随现实时间慢慢下降；快乐值较低时可以一键出门旅游。
- 每次旅行需要 3 份食物和 3 份水，默认新玩家拥有 5 份食物和 5 份水。
- 食物和水可以用啃叽币购买，每份 1 啃叽币。
- 旅行持续约 60 秒。旅行结束后啃叽会变脏，并消耗一定饱腹值。
- 啃叽变脏后需要点击“给啃叽洗澡”，洗完才能再次旅行。
- 旅行状态保存在服务器数据中；如果服务器重启后旅行时间已到，玩家下次刷新数据时会自动结算为“旅行结束、需要洗澡”。
